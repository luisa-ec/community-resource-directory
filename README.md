
# Community Resource Directory

## Project Overview

The Community Resource Directory is a responsive website designed to help local residents discover community support services.

The project is being developed as part of the Ishvexa Hub Web Development Internship.

## Intended Users

Local residents looking for education, employment, health, housing, or youth-support resources.

## Features

- Browse community resources
- Search resources by keyword
- Filter resources by category
- View resource information
- Responsive layout for mobile and desktop

## Technologies

- HTML
- CSS
- JavaScript

## Project Pages

1. Home
2. Resources
3. About / Contact

## Setup

This project is a static website.

To run it locally, open `index.html` in a web browser.

A local development server may be used during development.

## Data and Disclaimer

All resource names, services, and contact details used in the project are fictional examples created for demonstration purposes.

This project does not provide real community services.
